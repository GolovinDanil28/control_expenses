# reports

## Purpose

Содержание отчётов: сводка по произвольному периоду, сравнение с предыдущим
периодом, наполнение недельной сводки. Отправкой по расписанию управляет
`reminders`.

## Requirements

### Requirement: Отчёт по произвольному периоду
Система SHALL формировать отчёт о тратах за выбранный период: суммы по
категориям, итог, а для месячного отчёта — план, остаток и дневную норму.

#### Scenario: Отчёт за диапазон дат
- **WHEN** владелец отправляет `/report 01.10 07.10`
- **THEN** система показывает отчёт за указанный период с суммами по категориям
- **AND** в отчёте указана общая сумма трат за период

#### Scenario: Отчёт за месяц
- **WHEN** владелец отправляет `/report` без аргументов
- **THEN** система показывает отчёт за текущий месяц
- **AND** в отчёте указаны план, потраченное, остаток и дневная норма

#### Scenario: Отчёт без данных
- **WHEN** в указанном периоде нет трат
- **THEN** система сообщает, что трат за период не было
- **AND** не показывает пустые категории

#### Scenario: Некорректный период
- **WHEN** даты в запросе нечитаемы или конец периода раньше начала
- **THEN** система отказывается формировать отчёт
- **AND** объясняет причину ошибки

### Requirement: Сравнение с предыдущим периодом
Система SHALL показывать изменение суммы трат относительно предыдущего
аналогичного периода, если за него есть данные.

#### Scenario: Данные за предыдущий период есть
- **WHEN** владелец запрашивает отчёт за месяц
- **AND** за предыдущий месяц есть траты
- **THEN** отчёт содержит изменение суммы к предыдущему месяцу

#### Scenario: Данных за предыдущий период нет
- **WHEN** владелец запрашивает отчёт за первый учтённый месяц
- **THEN** отчёт не содержит сравнения
- **AND** ошибка не показывается

### Requirement: Наполнение недельной сводки
Система SHALL включать в недельную сводку итоги трат за последнюю неделю по
категориям, план на текущий месяц, дневную норму и ближайшие обязательства.

#### Scenario: Сводка с тратами
- **WHEN** за последнюю неделю были траты
- **THEN** сводка содержит суммы по категориям за неделю
- **AND** сводка содержит дневную норму на текущий месяц
- **AND** сводка содержит ближайшие обязательства

#### Scenario: Сводка без трат
- **WHEN** за последнюю неделю трат не было
- **THEN** сводка содержит план на месяц и дневную норму
- **AND** сводка не содержит пустых категорий

#### Scenario: Недостаточно данных для сводки
- **WHEN** за последнюю неделю нет трат и бюджет месяца не настроен
- **THEN** сводка сообщает о недостатке данных
- **AND** подсказывает, как настроить бюджет и записать первую трату

### Requirement: Приватность отчёта
Система SHALL NOT включать в отчёт идентификаторы чатов, имена авторов трат и
служебные идентификаторы сообщений.

#### Scenario: Отчёт за период с тратами из разных допущенных чатов
- **WHEN** владелец запрашивает отчёт за период, содержащий траты из нескольких допущенных чатов
- **THEN** отчёт содержит только суммы, категории и даты
