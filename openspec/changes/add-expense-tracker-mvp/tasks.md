# Tasks: add-expense-tracker-mvp

Порядок внутри change: спецификация → падающий тест → реализация → рефакторинг.
Один пункт ≈ один коммит с проверяемым результатом. Требования и сценарии
зафиксированы в `specs/`; ниже — план реализации MVP по слоям.

Объём сделанного на 2026-10-16 — **сквозной срез**: «текст → карточка →
подтверждение → строка в SQLite». Всё остальное — по capability, ниже.

- [x] 1.1 `money.py`: `Money` — рубли с точностью до копейки, из/в копейки, ±, деление вниз, формат «1 250 ₽ 50 коп»; тесты границ.
- [x] 1.2 `errors.py`: типизированные доменные исключения.
- [x] 1.3 `categories.py`: предопределённый справочник, нормализация по регистру, проверка дубликата.
- [x] 1.4 `entities.py`: `Expense`, `Commitment` (fixed/variable/meter), `CommitmentOccurrence`, валидации.
- [x] 1.5 `budget.py`: `days_left_in_month`, `committed_total`, `BudgetStatus` (remaining/daily/overrun), `threshold_reached`; тесты сценариев `budgets`.

## 3. Приложение (`application/`)

- [x] 3.1 Порты среза: `Clock`, `IntentParser`, `ExpenseRepository`, `CategoryRepository`, `PendingInputStore`.
- [x] 3.2 Порты оповещений: `NotificationLog`, `SettingsRepository`, `MessageSender`, `WeeklySummary`, `DueCommitments`.
- [x] 3.3 Use case `expenses`: карточка → подтверждение/отмена, игнор предыдущей карточки, правка суммы и категории, явная дата (в т.ч. `12.10`) с отказом для даты в будущем, `/addcategory`.

- [x] 3.9 `ai-insights`: LLM-разбор за портом `IntentParser`, валидация ответа (сумма/категория/дата), нормализация категории, минимальный промпт, деградация на детерминированный разбор.
- [x] 3.10 Тесты use case `expenses` на фейковых портах.
